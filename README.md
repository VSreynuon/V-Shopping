# V-Shopping

A realistic frontend fashion e-commerce project built with HTML, CSS, JavaScript, Bootstrap and Font Awesome.

## Features
- Responsive fashion homepage
- Product categories
- Search, filtering and sorting
- Product details
- Size and color selection
- Shopping cart
- Wishlist
- Register/login/logout
- Profile
- Checkout
- Order history
- LocalStorage persistence

## Run
Open `index.html` in a browser or use VS Code Live Server.

Internet is required for Bootstrap, Font Awesome and online product images.

## Note
This is a frontend demo. Authentication and orders use browser LocalStorage. A production website needs a secure backend, database, API, server-side validation and real payment integration.
